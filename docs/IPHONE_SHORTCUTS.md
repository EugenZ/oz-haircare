# Apple Shortcuts («Команды»): SMS и Instagram клиентам от имени Ольги

Сообщения клиентам (подтверждение, предложение другого времени, отказ) сайт
не отправляет сам — он кладёт их в очередь `outbox`, а iPhone Ольги забирает
их через приложение **Apple Shortcuts («Команды» в русской iOS)** и отправляет:

- **SMS — полностью автоматически.** От Ольги нужно только одно касание
  «Подтвердить» на странице заявки; дальше SMS уходит с её iPhone сам, по
  автоматизации, без её участия.
- **Instagram — полуавтоматически, это единственный шаг, где нужно её
  касание.** Команда копирует текст и открывает переписку
  `https://ig.me/m/<ник>`, Ольга вставляет текст и нажимает «Отправить».
  Официальный API Instagram не позволяет первым написать произвольному
  пользователю, поэтому автоматизировать это нельзя.

Названия действий ниже даны как в русской iOS, в скобках — в английской.

Сообщения появляются в очереди **только после действия Ольги** (подтвердить /
отклонить / предложить время) или после ответа клиента на предложение.

## API

Оба запроса требуют заголовок `Authorization: Bearer <OUTBOX_API_TOKEN>`
(значение — из секретов Worker, в репозитории его нет).

### 1. Забрать сообщения — `POST /api/outbox/claim`

Тело (JSON):

```json
{ "channel": "sms", "limit": 10 }
```

`channel` — `sms` или `instagram`. Ответ:

```json
{
  "ok": true,
  "channel": "sms",
  "count": 1,
  "items": [
    {
      "id": 17,
      "bookingId": 42,
      "channel": "sms",
      "kind": "confirmed",
      "claim": "6f1c…",
      "text": "Здравствуйте, Анна! Ольга (OZ SPA) подтвердила вашу запись: …",
      "phone": "+13105550123",
      "attempts": 1,
      "ackUrl": "https://SITE/api/outbox/17/ack"
    }
  ]
}
```

Для `instagram` вместо `phone` приходят `handle` и `url`
(`https://ig.me/m/<handle>`).

Каждое выданное сообщение «арендуется» на 2 часа. Если подтверждение (ack) не
пришло, после аренды сообщение выдаётся ещё раз — **максимум 2 попытки**, затем
оно помечается `failed`. То есть потерянный ack может привести максимум к
одному дублю.

### 2. Подтвердить отправку — `POST {ackUrl}`

```json
{ "claim": "6f1c…", "result": "sent" }
```

или при ошибке `{ "claim": "…", "result": "failed", "error": "…" }` —
сообщение вернётся в очередь (если попытки остались). Повторный ack уже
отправленного сообщения безопасен (200).

## Команда «OZ SMS» (полностью автоматическая)

1. **«Текст»** (Text) → вставьте `OUTBOX_API_TOKEN` прямо в действие. Не
   читайте токен из файла iCloud или заметки: на заблокированном телефоне
   такие файлы могут быть недоступны.
2. **«Получить содержимое URL»** (Get Contents of URL)
   - URL: `https://SITE/api/outbox/claim`
   - Метод: `POST`
   - Заголовки: `Authorization` = `Bearer <Текст>`
   - Тело запроса: JSON → `channel` = `sms`, `limit` = `10`
3. **«Получить значение словаря»** (Get Dictionary Value) для `items`.
4. **«Повторить с каждым»** (Repeat with Each) объектом в `items`:
   1. **«Получить значение словаря»** для `phone`, `text`, `ackUrl`, `claim`
      из «Объект повтора» (Repeat Item).
   2. **«Отправить сообщение»** (Send Message): текст `text`, получатель
      `phone`. Раскройте действие и **выключите «Показывать при запуске»**
      (Show When Run) — иначе iOS откроет окно и будет ждать касания.
   3. **«Получить содержимое URL»**: URL = `ackUrl`, метод `POST`, тот же
      заголовок `Authorization`, тело JSON → `claim` = `claim`, `result` = `sent`.
5. Конец повтора.

### Автоматизация «каждые 30 минут»

В iOS нет триггера «каждые N минут», поэтому заводим несколько автоматизаций
**«Время суток»** (Time of Day) в «Команды» → «Автоматизация» (Automation):

- 09:00, 09:30, 10:00, … 20:00 (сколько нужно), повтор «Ежедневно» →
  действие «Запустить команду» (Run Shortcut) → «OZ SMS»;
- в каждой выберите **«Выполнять сразу»** (Run Immediately) и **выключите
  «Уведомлять при запуске»** (Notify When Run).

### Ограничения

- iPhone должен быть включён и в сети (интернет для запроса к сайту, сотовая
  связь для SMS). Если телефон был выключен, сообщения уйдут при следующем
  запуске автоматизации — они ждут в очереди.
- Разблокировать телефон обычно не нужно: автоматизация «Время суток» с
  «Выполнять сразу» работает и на заблокированном экране. Но некоторые версии
  iOS всё же просят разблокировку или подтверждение для «Отправить сообщение»,
  поэтому один раз проверьте по списку ниже.
- Режим энергосбережения и «Фокус» могут задержать запуск на несколько минут —
  это не страшно.
- Если у клиента iMessage, «Сообщения» отправят iMessage вместо SMS — это
  нормально.

### Разовая проверка на iPhone Ольги

1. Посмотрите версию iOS: «Настройки» → «Основные» → «Об этом устройстве».
2. Создайте тестовую заявку на сайте со своим номером и подтвердите её.
3. Поставьте автоматизацию на ближайшие 2–3 минуты, **заблокируйте телефон**
   и не трогайте его.
4. Убедитесь, что SMS пришло, не появилось ни окна, ни запроса подтверждения,
   а повторный запуск команды ничего не отправляет (`count` = 0, сообщение
   помечено отправленным).
5. Если iOS всё же спросила подтверждение: проверьте «Выполнять сразу»
   и «Показывать при запуске»; если не помогло — на этой версии iOS отправка
   без касания невозможна, и вопрос нужно решать отдельно (например, другой
   способ отправки SMS).

## Команда «OZ Instagram» (полуавтоматическая — нужно касание Ольги)

Те же шаги 1–3, но `channel` = `instagram`. В начало добавьте: «Если» (If)
`count` = 0 → «Показать уведомление» «Нет сообщений» → «Остановить команду».
Внутри «Повторить с каждым»:

1. **«Получить значение словаря»** для `text` → **«Скопировать в буфер»**
   (Copy to Clipboard).
2. **«Получить значение словаря»** для `url` → **«Открыть URL»** (Open URLs) —
   откроется переписка с клиентом в Instagram.
3. **«Ждать возврата»** (Wait to Return): Ольга вставляет текст, нажимает
   «Отправить» и возвращается в «Команды».
4. **«Выбрать из меню»** (Choose from Menu) «Отправлено?»:
   - «Да» → «Получить содержимое URL» `POST ackUrl` с `{ "claim": claim, "result": "sent" }`;
   - «Нет» → `POST ackUrl` с `{ "claim": claim, "result": "failed", "error": "skipped" }`.

Эту команду Ольга запускает сама (виджет или иконка на экране «Домой»),
например после письма о подтверждённой записи. Автоматизация здесь не
поможет: отправку в Instagram всё равно нажимает она.

## Безопасность

- `OUTBOX_API_TOKEN` — длинная случайная строка (`openssl rand -base64 32`),
  задаётся как секрет Worker (`wrangler secret put OUTBOX_API_TOKEN`) и в
  действии «Текст» обеих команд. Без этого значения оба эндпоинта отвечают `401`.
- Тексты сообщений содержат ссылку на страницу записи клиента
  (`/booking/view?id=…&v=…`) с одноразово сгенерированным токеном; в базе
  хранится только его SHA-256.
